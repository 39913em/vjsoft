# Vídeos — carpeta opcional

**Lo más fácil NO usa esta carpeta:** arrastra tus vídeos a la ventana de la consola (o usa el botón
"Añadir modelos .glb / vídeos…") y listo. Mira el README.

Esta carpeta sirve solo para dejar vídeos *fijos dentro del proyecto*: copia aquí los archivos
(`.mp4`, `.webm`, `.ogv`, `.m4v`), ejecuta `node tools/sync-clips.js` y abre el proyecto con servidor local.
